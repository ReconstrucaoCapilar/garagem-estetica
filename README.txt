GARAGEM ESTÉTICA — versão para GitHub

Estrutura:
- index.html
- assets/ (todas as imagens utilizadas pelo site)

Para publicar no GitHub Pages:
1. Envie o conteúdo desta pasta para o repositório.
2. Mantenha a pasta assets no mesmo nível do index.html.
3. Ative GitHub Pages usando a branch/pasta onde está o index.html.

Correção desta versão:
- Card Jeep Renegade usa a imagem correta do Jeep (galeria-suv.png).
- Card Honda Biz usa a imagem correta da Honda CB 500F (galeria-honda-cb500f.png).
